كتالوج البوتات المجتمعية إصدار 1.21.0

بوتات جاهزة بقوالب موثقة تعمل في قنوات المجتمعات وغرفها — كل بيان موقّع بـHMAC-SHA256 وتُفحص حدود قوالبها قبل العرض لا بعده. هذه الصفحة توثق الصيغة العامة؛ الكتالوج الحي يُدار من شاشة البوتات داخل التطبيق على واجهة HMAC القائمة نفسها.

القوالب الجاهزة الثلاثة

ترحيب

من 1 إلى 3 رسائل، كل رسالة حتى 200 حرف، ومتغير {name} يستبدل باسم المستقبل عند الترحيب.

حضور

من 1 إلى 2 جلسة، بصيغة HH:mm، والبداية قبل النهاية — يعلن أوقات الحضور كما وثقها صاحب البوت.

اقتراحات

من 3 إلى 5 عناصر، كل عنصر حتى 80 حرفاً — قائمة مقترحات ثابتة يعرضها البوت لمجتمعه.

كيف يوثَّق البيان؟

نفس بوابة الويب هوك القائمة منذ البداية: توقيع X-Wasl-Signature بصيغة sha256=HMAC(جسم البيان، السرّ)، ومقارنة زمن-ثابت، والترميز القانوني هو ترميز JSON القياسي للبيان — ومن يقبل البيان يتحقق بالدالة نفسها فلا خلاف ترميز ولا بيان معبث يمر. 

{
  "version": 1,
  "bots": [
    {
      "manifest": {
        "username": "helper_bot",
        "displayName": "المساعد",
        "description": "بوت ترحيب لمجتمعات وصل",
        "templates": [
          { "type": "welcome",
            "messages": ["أهلاً {name}!", "كيف أساعدك اليوم؟"] }
        ]
      },
      "signature": "sha256=…"
    }
  ]
}
  • الاسم البرمجي يلتزم صيغة الواجهة: ينتهي بـ_bot.
  • الترتيب القياسي تصاعدياً بالاسم البرمجي شرط اعتماد — لا كتالوج يتبدل بترتيب وصوله.
  • التكرار مرفوض والسعة 12 بوتاً للكتالوج و3 لكل غرفة.
  • الفشل يعيد أسبابه مجمعة لا أولها — لا استثناءات مسربة.

حدود صادقة

المحرك النقي wasl_bots بلا شبكة ولا ملفات: بايتات داخل ونتائج خارج، فالتوقيع والفحص قابلان للتشغيل محلياً بنفسك. وربط الغرف الحي عبر خدمة التطبيق يُنشر بكود التطبيق المفتوح في المستودع، والبوتات تعمل فعلياً في القنوات وغرف المجتمعات (محتواها صريح بالتصميم) — الغرف المشفرة طرف-لطرف نصها لا يفكه بوت أصلاً.
