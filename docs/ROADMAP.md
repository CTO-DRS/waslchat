# خارطة طريق وصل شات

آخر تحديث: 2026-11-08 · الإصدار الحالي: **0.4.0+19**

## الرؤية
تطبيق مراسلة عربي أولاً، ينافس واتساب وتيليجرام وديسكورد في مكان واحد:
- **خصوصية واتساب** (تشفير تام بين الطرفين افتراضياً).
- **قوة تيليجرام** (قنوات كبيرة، ملفات، بوتات، تعدد أجهزة).
- **مجتمعات ديسكورد** (غرف، أدوار، صوت حي).
- **ذكاء وصل AI** يحترم الخصوصية (على الجهاز حيث أمكن).
- **تصميم 2036**: زجاجي، سريع، عربي من اليمين لليسار بإتقان.

## المبادئ الثابتة
1. الخصوصية قبل الميزة: أي ميزة تكشف المحتوى للخادم تُوضَّح للمستخدم أو لا تُنفَّذ.
2. لا وعود غير صادقة: لا نقول «مشفّر تماماً» عن شيء غير مشفّر.
3. ميزانية صفر حتى الإطلاق: أدوات مجانية ومفتوحة المصدر وطبقات مجانية.
4. كل إصدار: `flutter analyze` نظيف، الاختبارات ناجحة، ترحيل SQL مرقّم، APK موقّع بنفس المفتاح.
