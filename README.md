### الجديد في 0.13.0 — اكتملت المرحلة 4 (قوة تيليجرام)
- **«رسائلي المحفوظة» كسحابة شخصية**: صف مثبّت أعلى قائمة المحادثات يحفظ رسائلك وملفاتك ووسائطك لكل أجهزتك — وتُشفَّر بمفتاح يُغلِّف لنفسك بنفس تقنية المجموعات فيخزنها الخادم مشفرة كأي محادثة، وهي أول هدف دائم في ورقة إعادة التوجيه.
- **أسماء المستخدم بروابط `waslchat.app/@user`**: غيّر اسمك من ملفك الشخصي بفحص توفر حي (4–24 حرفاً إنجليزياً ورقماً وشرطة سفلية، وكلمات محجوزة، وتغيير مرة كل 24 ساعة)، وانسخ رابط ملفك العام، وابحث عن أي حساب بكتابة @username أو لصق الرابط كاملاً — المطابقة التامة تظهر أعلى النتائج.
- **بوتات وواجهة مطوّرين موقّعة (Webhooks)**: كل بوت حساب آلي حقيقي باسم ينتهي `_bot`، رمز واجهة `wasl_` يظهر مرة واحدة ويُخزَّن مُجزّأً، وخمس طرق REST (getMe وsendMessage وeditMessageText وdeleteMessage وgetChat) بحد 20 رسالة/دقيقة و10 بوتات لكل مالك، وويب هوك يستقبل رسائل المحادثات التي يشارك فيها البوت موقّعة HMAC-SHA256، وكتم المجتمع يسري على البوت كأي عضو. بصدق: محادثة البوت المباشرة غير مشفرة طرف-لطرف (لافتة توضح ذلك)، وفي المجموعات الخاصة المشفرة يصل النص مشفراً لا يفكه — بوتاتك تعمل بأمانة كاملة في القنوات وغرف المجتمعات. التوثيق الكامل: `docs/BOTS_API.md`، والوصول من الإعدادات ← البوتات وواجهة المطوّرين.
- **قنوات كبيرة بإحصاءات المشاهدة**: عدّاد 👁 تحت كل منشور يراه كل متابعي القناة بتنسيق عربي (1.3 ألف مشاهدة)، وورقة «إحصاءات القناة» لمشرفيها (المتابعون والإجمالي والمتوسط وآخر 30 منشوراً بعدّاداتها) من شريط شاشة القناة.
- **نسخة سطح المكتب**: سير بناء جديد يبني ويندوز ولينكس وماك عند كل وسم إصدار `v*` في GitHub Actions ويرفع النسخ جاهزة — النسخة الويب الكاملة تعمل أصلاً وتشمل كل ميزات هذا الإصدار.
- **يتطلب**: تشغيل `supabase/025_phase4.sql` في SQL Editor ثم نشر دالة `bots-api` (انظر `docs/RUNBOOK_URGENT.md` §6 بند 11 و§3.4). بلا ترحيل: لا صف محفوظة ولا تغيير اسم ولا شاشة بوتات فعّالة ولا عدّادات — ولا يتعطل شيء آخر.

### الجديد في 0.12.0
- **أحداث المجتمع وتذكيراتها** (من المرحلة 3 — مستوى ديسكورد): شاشة «الأحداث» في كل مجتمع (أيقونة التقويم للجميع) تعرض الأحداث القادمة والجارية بشارة «جارٍ الآن» والمنتهية قبل أسبوع. مشرفو المجتمع (ومنشئ الحدث) ينشئون حدثاً بعنوان ووصف ومكان أو رابط ووقت بدء ومدة (30 دقيقة → يوم كامل) ويعدّلونه أو يحذفونه قبل بدئه؛ وكل عضو يجيب على الحضور بضغطة: **سأحضر / ربما / لن أحضر** — مع عدّادات وأسماء المجيبين ظاهرة في ورقة التفاصيل، والضغط على ردّك نفسه يلغيه. والتذكير من الخادم لا من التطبيق: قبل بدء الحدث بالمدة التي اختارها منشؤه (15 دقيقة → 24 ساعة) يصل كل الأعضاء إشعار «📅 عنوان الحدث — يبدأ بعد…» مرة واحدة مهما كان التطبيق مغلقاً. الفرض من الخادم: غير المشرف لا ينشئ ولا يحذف، والأحداث لا يراها إلا أعضاء المجتمع، والرد على حدث منتهٍ مرفوض.

### الجديد في 0.7.5
- **التحقق من رمز الأمان بمسح QR** (من المرحلة 2): من حوار رمز الأمان في أي محادثة فردية زر جديد «تحقق بمسح رمز QR» — شاشتك تعرض رمز QR يحمل هوية حسابك ومفتاحك العام، وتمسح رمز الطرف الآخر بالكاميرا. عند التطابق يوثَّق مفتاحه محلياً على جهازك: أيقونة خضراء في شريط المحادثة، وإذا غيّر الطرف مفتاحه يتلغى التوثيق تلقائياً ويظهر التنبيه الأصلي. عند مسح رمز بمفتاح مختلف عن المنشور للحساب نفسه يظهر **تحذير أمني أحمر** بعدم التوثيق (احتمال انتحال)، وكذلك لمن يمسح رمز حساب آخر. التوثيق محفوظ في مخزن آمن على جهازك فقط ولا يُرفع للخادم، والمقارنة اليدوية الستينية تبقى خياراً احتياطياً وعلى الويب.

## التشغيل خطوة بخطوة (مجاناً)
تحتاج كمبيوتر (ويندوز أو ماك أو لينكس).

1. **ثبّت Flutter**: من flutter.dev > Get started، ثم شغّل `flutter doctor`.
2. **أنشئ مشروع Supabase مجاني**: supabase.com > New project.
3. **قاعدة البيانات**: افتح SQL Editor، الصق `supabase/001_schema.sql` واضغط Run، ثم `002_groups_media.sql`، ثم `003_receipts_push.sql`، ثم `004_communities_channels.sql`، ثم `005_push_trigger.sql` (بقيم حقيقية)، ثم `006_e2e_keys.sql` (كل ملف وحده ثم Run).
   (إذا شغّلت إصداراً سابقاً، شغّل الملفات الجديدة فقط.)
4. **للتجربة السريعة**: Authentication > Providers > Email، أطفئ "Confirm email".
5. **اربط التطبيق**: من Project Settings > API انسخ Project URL و anon key وضعهما في `lib/config.dart`.
6. **جهّز المجلد** (داخل مجلد المشروع):
   ```
   flutter create . --project-name wasl_chat --platforms=android,ios,web
   flutter pub get
   ```
7. **الأذونات** (مرة واحدة بعد الخطوة 6):
   - أندرويد: في `android/app/src/main/AndroidManifest.xml` أضف فوق `<application`:
     ```
     <uses-permission android:name="android.permission.INTERNET"/>
     <uses-permission android:name="android.permission.RECORD_AUDIO"/>
     ```
   - آيفون: في `ios/Runner/Info.plist` أضف داخل `<dict>`:
     ```
     <key>NSMicrophoneUsageDescription</key><string>لتسجيل الرسائل الصوتية</string>
     <key>NSCameraUsageDescription</key><string>لالتقاط الصور وإرسالها</string>
     <key>NSPhotoLibraryUsageDescription</key><string>لإرسال الصور من المعرض</string>
     ```
8. **شغّل**: `flutter run` (على جوال موصول أو `flutter run -d chrome`).
9. **جرّب**: أنشئ حسابين (مثلاً من المتصفح والجوال) وابدأ محادثة بينهما.

> ملاحظة: التسجيل الصوتي يعمل على تطبيق الجوال، والصور تعمل على الجوال والويب.

## وصل AI (مجاني)
1. خذ مفتاحاً مجانياً من aistudio.google.com/apikey (بدون بطاقة).
2. من مجلد المشروع:
   ```
   npx supabase secrets set GEMINI_API_KEY=مفتاحك
   npx supabase functions deploy ai
   ```
   (إذا لم تربط المشروع بعد: `npx supabase login` ثم `npx supabase link --project-ref رمز-مشروعك`.)
3. النموذج الافتراضي `gemini-3.8-flash`. لتغييره: `npx supabase secrets set GEMINI_MODEL=اسم-النموذج`.
> الطبقة المجانية لها حد يومي للطلبات، وجوجل قد تستخدم بياناتها لتحسين منتجاتها. للخصوصية الكاملة لاحقاً ننتقل للطبقة المدفوعة أو نموذج مفتوح.

## الإشعارات (اختياري، مجاني على أندرويد)
بدونها يعمل التطبيق كاملاً، فقط لا تصل تنبيهات والتطبيق مغلق.
1. أنشئ مشروعاً مجانياً في console.firebase.google.com.
2. على كمبيوترك:
   ```
   npm install -g firebase-tools
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   (يستبدل `lib/firebase_options.dart` تلقائياً.)
3. في Firebase: Project settings > Service accounts > Generate new private key. احفظ الملف باسم `sa.json`.
4. انشر دالة الإشعارات على Supabase (من مجلد المشروع):
   ```
   npx supabase login
   npx supabase link --project-ref رمز-مشروعك
   npx supabase secrets set FCM_SERVICE_ACCOUNT="$(cat sa.json)" WEBHOOK_SECRET=اختر-كلمة-سرية-طويلة
   npx supabase functions deploy push --no-verify-jwt
   ```
5. في Supabase: Database > Webhooks > Create: الجدول `messages`، الحدث Insert، النوع Supabase Edge Functions، الدالة `push`، وأضف Header باسم `x-webhook-secret` وقيمته نفس الكلمة السرية.
6. أندرويد 13+: أضف في AndroidManifest:
   `<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>`

> آيفون: الإشعارات تتطلب حساب Apple Developer المدفوع (99$ سنوياً)، لذلك نبدأ بأندرويد.
> لا تشارك `sa.json` مع أحد ولا ترفعه على GitHub.
