# wasl_mediastudio — استوديو الوسائط الموحد

المحرك النقي الثاني عشر من محركات وصل. ينفذ بند 1.20.0 «محرر وسائط محلي
واحد يجمع: قص الصور والتدوير والتعليقات والدمج» كنواة نقية فوق `image`
4.x المحلية — كل المعالجة على الجهاز حصراً وبنيةً: لا مكتبات ملفات ولا
شبكة في المحرك، يأخذ بايتات ويعيد بايتات فالرفع غير ممكن منه أصلاً.

## العقد الصادق

1. **حدود معلنة قبل التنفيذ لا بعده**: حجم المدخل (24 م.ب توافقاً مع
   `MediaLimits`) وبكسلاته (4096×4096) وعدد العمليات (12) وطول التعليق
   (64) وبلاطات الدمج (6) — **تُجمع كل الأسباب لا أولها**، والحدود قابلة
   للحقن للاختبار.
2. **رفض صريح لا صمت**: القص خارج الحدود يرفض، والزاوية غير مضاعفة 90
   ترفض، والتصغير لا يكبّر أبداً (تكبير = ضباب صامت)، والتدوير والقلب
   **بخرائط فهرس حرفية** — بلا إعادة أخذ عينات تفسد البكسل (التشخيص أثناء
   البناء أمسك `copyRotate` وهي تفسد القيم بصمت).
3. **التعليقات صادقة**: الخطوط النقطية المدمجة لاتينية حصراً — التعليق
   العربي لا يُرسم بكسلاً بل يُحمل في `uiCaptions` للواجهة فترسمه بخطوط
   Flutter، والتحذير يعلن ذلك.
4. **حتمية**: نفس المدخل والعمليات = بايتات متطابقة حرفياً.
5. **الحد الصادق**: لا حفظ ملفات ولا رفع ولا معاينات هنا — طبقة التطبيق؛
   وبحث نص التفريغ الصوتي ينتظر مصدر التفريغ (مؤجل خلف بوابة القياس
   1.18.0 — لا كود ميتاً بلا مستدعي).
