# wasl_bots — كتالوج البوتات المجتمعية

المحرك النقي الثالث عشر من محركات وصل. ينفذ بند 1.21.0 «كتالوج بوتات
مجتمعية موثق بقوالب جاهزة (ترحيب، حضور، اقتراحات) على واجهة HMAC القائمة»
كنواة نقية بلا أي اعتماديات — HMAC-SHA256 (RFC 2104) يدوياً فوق SHA-256
النقي المعاد استخدامه حرفياً من `sha256.dart` (محرك النماذج، FIPS 180-4).

## العقد الصادق

1. **التوقيع قبل الثقة**: صيغة `X-Wasl-Signature: sha256=HMAC(الجسم، السرّ)`
   القائمة منذ المرحلة 4 — والمقارنة زمن-ثابت، والمتجهات المرجعية من
   RFC 4231 (TC1 وTC2 وTC3 وTC6 وTC7) محسوبة خارجياً بـpython hmac
   مستقلة عن هذا التنفيذ.
2. **تقانون واحد للتوقيع**: `signManifest` يرمّز البيان بترميز JSON
   القياسي ثم يوقّع — الناشر والمستهلك بهذا الدالة نفسها فلا خلاف ترميز.
3. **القوالب بحدود معلنة**: ترحيب 1..3 رسائل ≤200 حرف، حضور 1..2 جلسة
   HH:mm بداية<نهاية، اقتراحات 3..5 ≤80 حرفاً — المخالفات تتجمع لا أولها.
4. **حتمية**: نفس القالب والمدخلات = نص متطابق حرفياً.
5. **الكتالوج بترتيب قياسي**: تصاعدياً بالاسم البرمجي والتكرار مرفوض
   والسعة ≤12 — لا كتالوج يتبدل بترتيب وصوله.
6. **الحد الصادق**: بلا شبكة ولا تخزين وصفحة اكتشاف هنا (طبقة النشر) —
   والربط الحي للغرف عبر `bot_catalog_service` في التطبيق.
