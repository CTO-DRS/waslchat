# wasl_fieldgate — بوابة القياس الميداني

المحرك النقي العاشر من محركات وصل. الشرط البنيوي الحرفي من GRAND_PLAN_3
(1.18.0): «بوابة لكل بند: قياس ميداني قبل النشر، والنتائج معروضة صادقاً —
والبند الذي لا يجتاز يُعلن مؤجلاً في الشفافية لا يُشحَن ناقصاً».

## العقد الصادق

1. **العتبات قبل القياس**: `FeatureThresholds.defaults` تعلن أرقام الخارطة
   (≥ 20 رمز/ث، أول رمز ≤ 2000 م.ث، استنزاف ≤ 1%/د، ذاكرة ≥ 4096 م.ب) —
   ولا تُعدَّل بعد القياس.
2. **الحكم ثنائي**: `pass` أو `deferred` — لا حالة وسيطة ولا «شبه جاهز».
3. **كل الأسباب لا أولها**: عتبات فاشلة متعددة تجمع أسبابها كلها في الحكم
   الواحد كي يرى المطور الصورة كاملة قبل أي إصلاح.
4. **السجل يمنع قلب القرار**: `GateLedger.canShip` يسأل عن آخر حكم معلن
   حصراً — بند لم يقاس أصلاً لا يُشحن، ومؤجل لا يُشحن حتى بقياس جديد يجتاز.
5. **التقرير كما قيس**: `TransparencyReport.render` نص بأرقام القياس الحرفية
   وأسباب التأجيل وملاحظات القياس — جاهز للصق في TRANSPARENCY.md.
