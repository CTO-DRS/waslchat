# wasl_translate — محرك نقّي من وصل شات

الترجمة القاموسية المحلية عربي↔إنجليزي بلا شبكة: عبارات المراسلة أولاً بتغطية معلنة وتطبيع الهمزات والتشكيل — نقية

## المصدر والإثبات

- المصدر الحرفي: **lib/services/local_translate_service.dart + local_ai_service.dart** عند إصدار وصل **1.9.0+71** (2026-11-18).
- المصدر منسوخ **حرفياً بلا أي تعديل** عن كود التطبيق الذي يجتاز تحليله النظيف واختباراته الكاملة (760/760 عند 1.8.0) — والاختبارات هنا نفسها مكيَّفة الاستيراد فقط.
- **بلا أسرار بلا استثناء**: تتحقق بنفسك عبر `scripts/scrub_engines.py` في مستودع وصل الرئيسي — يمسح كل ملف هنا بحثاً عن رموز ومفاتيح وعناوين مشاريع، والنتيجة صفر.
- القطع مُجمّدة (snapshot): تُحدَّث يدوياً عند تغيّر الأصل في التطبيق، والمطابقة تحقيق وثائقي لا آلي.

## الاستعمال

```dart
import 'package:wasl_translate/wasl_translate.dart';
```

الملف المدخل `wasl_translate.dart` يصدّر كل المصادر أدناه، ويمكن استيراد كل ملف مباشرة.
