# wasl_semantic — محرك نقّي من وصل شات

البحث الدلالي المتجهي على الجهاز: متجهة كيس كلمات معايرة (1+ln) وتوسيع مرادفات وتشابه جيب التمام — نقية بلا شبكة

## المصدر والإثبات

- المصدر الحرفي: **lib/services/semantic_search_service.dart + smart_search_service.dart** عند إصدار وصل **1.9.0+71** (2026-11-18).
- المصدر منسوخ **حرفياً بلا أي تعديل** عن كود التطبيق الذي يجتاز تحليله النظيف واختباراته الكاملة (760/760 عند 1.8.0) — والاختبارات هنا نفسها مكيَّفة الاستيراد فقط.
- **بلا أسرار بلا استثناء**: تتحقق بنفسك عبر `scripts/scrub_engines.py` في مستودع وصل الرئيسي — يمسح كل ملف هنا بحثاً عن رموز ومفاتيح وعناوين مشاريع، والنتيجة صفر.
- القطع مُجمّدة (snapshot): تُحدَّث يدوياً عند تغيّر الأصل في التطبيق، والمطابقة تحقيق وثائقي لا آلي.

## الاستعمال

```dart
import 'package:wasl_semantic/wasl_semantic.dart';
```

الملف المدخل `wasl_semantic.dart` يصدّر كل المصادر أدناه، ويمكن استيراد كل ملف مباشرة.
