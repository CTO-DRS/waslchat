# wasl_model_gate — محرك نقّي من وصل شات

بوابة تقييم تشغيل نموذج لغوي على الجهاز: قراءة الذاكرة من /proc/meminfo وحكم مرشّح الأعمق الممكن بهامش معلن — نقية بلا إذن ولا شبكة

## المصدر والإثبات

- المصدر الحرفي: **lib/services/on_device_model_service.dart** عند إصدار وصل **1.9.0+71** (2026-11-18).
- المصدر منسوخ **حرفياً بلا أي تعديل** عن كود التطبيق الذي يجتاز تحليله النظيف واختباراته الكاملة (760/760 عند 1.8.0) — والاختبارات هنا نفسها مكيَّفة الاستيراد فقط.
- **بلا أسرار بلا استثناء**: تتحقق بنفسك عبر `scripts/scrub_engines.py` في مستودع وصل الرئيسي — يمسح كل ملف هنا بحثاً عن رموز ومفاتيح وعناوين مشاريع، والنتيجة صفر.
- القطع مُجمّدة (snapshot): تُحدَّث يدوياً عند تغيّر الأصل في التطبيق، والمطابقة تحقيق وثائقي لا آلي.

## الاستعمال

```dart
import 'package:wasl_model_gate/wasl_model_gate.dart';
```

الملف المدخل `wasl_model_gate.dart` يصدّر كل المصادر أدناه، ويمكن استيراد كل ملف مباشرة.
